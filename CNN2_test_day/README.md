# test_day — วันแข่ง 25 ก.ย. (ใช้โมเดลของ CNN2)

ทุกอย่างของวันแข่งอยู่ในโฟลเดอร์นี้ **ไม่ต้องไปแตะไฟล์อื่นใน CNN2** — ส่งโฟลเดอร์นี้โฟลเดอร์เดียวให้เพื่อนได้ (มี `model.pt` อยู่ในนี้แล้ว)

## มี 2 เวอร์ชัน: "ฝัง" (embed) กับ "ไม่ฝัง" (noembed)

ชื่อไฟล์เป็นภาษาอังกฤษล้วน (กันปัญหาชื่อไทยบนบางเครื่อง): `embed` = ฝัง, `noembed` = ไม่ฝัง

ต่างกันที่เดียว คือ **ตารางแปลงโฟลเดอร์ → class_id** (72 คู่) ผลทำนายเหมือนกันทุกแถว (ทดสอบบนชุดจำลองได้ 117/120 ทั้งคู่)

| | **ฝัง (embed)** | **ไม่ฝัง (noembed)** |
|---|---|---|
| สคริปต์ | `predict_test_embed.py` | `predict_test_noembed.py` |
| ดับเบิลคลิก | `run_embed.bat` | `run_noembed.bat` |
| ตาราง class_id | มีสำเนาอยู่ในสคริปต์ และ **อ่านไฟล์ CSV ก่อนถ้ามี** | อ่านจากไฟล์ `Project_1-data_dict.csv` อย่างเดียว |
| ถ้าไม่มีไฟล์ CSV | รันได้ (ใช้ตัวฝัง + ขึ้น WARNING) | **หยุดทันที** `FileNotFoundError` |
| เหมาะเมื่อ | อยากกันพลาด ไฟล์หาย/ลืมส่งก็ไม่พัง (**แนะนำ**) | อยากให้ใช้ตารางจากไฟล์ที่อาจารย์ให้เท่านั้น ถ้าไฟล์ผิดจะรู้ทันที ไม่มีตัวสำรองเงียบ ๆ |

## พาธที่ใช้ และดึงภาพมายังไง

```
CNN2\
├─ model.pt                  ← ตัวเดิมใน repo (ทางสำรองของ run_*.bat)
└─ test_day\                 ← ยืนตรงนี้ตอนรัน
   ├─ model.pt
   ├─ predict_test_embed.py  /  predict_test_noembed.py
   ├─ Project_1-data_dict.csv
   ├─ run_embed.bat  /  run_noembed.bat
   └─ test_dataset\          ← วางเอง วันแข่ง
      ├─ ts_img_001.jpg
      └─ …
```

พาธมี 3 แบบ ต่างกันที่ "นับจากไหน":

1. **พาธในคำสั่ง** (`--model model.pt --test-dir test_dataset`) — ไม่มี `C:\...` นำหน้า แปลว่านับจาก **โฟลเดอร์ที่ยืนอยู่ตอนรัน** ดับเบิลคลิก `.bat` จะยืนที่ `test_day\` ให้เอง แต่ถ้ารันใน terminal ต้อง `cd` เข้า `test_day\` ก่อน (ยืนที่อื่นจะหาไม่เจอ) · `..` = โฟลเดอร์ชั้นบนหนึ่งชั้น `..\model.pt` จึงคือ `CNN2\model.pt`
2. **ตารางแปลง class_id** (`Project_1-data_dict.csv`) — นับจาก **ที่ตัวสคริปต์วางอยู่** (ในสคริปต์คือ `HERE`) ไม่ว่าจะยืนที่ไหนก็หาเจอ ขอแค่วางสคริปต์กับไฟล์นี้คู่กัน
3. **ข้อความ `./test_dataset/ts_img_001` ในไฟล์ผลลัพธ์** — **ไม่ใช่พาธที่ใช้อ่านภาพ** สคริปต์สร้างข้อความให้หน้าตาเหมือนคอลัมน์ `gt_path` ของโจทย์ (ตัด `.jpg` ออก) เพื่อไว้ตรวจแถวให้ตรงกับชีต

ขั้นตอนดึงภาพ:
1. `os.listdir(test_dataset)` → รายชื่อไฟล์ (**ไม่เข้าโฟลเดอร์ย่อย**)
2. เก็บเฉพาะ `.jpg .jpeg .png .bmp` แล้วเรียง "ตามเลข" (`ts_img_2` ก่อน `ts_img_10`) ให้ลำดับแถวตรงกับชีต
3. ต่อพาธเต็ม `test_dataset\ts_img_001.jpg` → เปิดภาพ → `.convert("RGB")` (ภาพขาวดำก็ผ่านได้)
4. `Resize(224×224)` → Normalize → ส่งเข้าโมเดลทีละ 64 ภาพ
5. ทายได้ลำดับ 0–71 → ตาราง `class_to_idx` ในโมเดลแปลงเป็นเลขโฟลเดอร์ → ตารางแปลงเป็น class_id

ภาพที่เปิดไม่ได้ สคริปต์ไม่พัง แต่เดาคลาส 210 และพิมพ์ WARNING ไว้

ที่ต้องระวัง:
- **ยืนผิดโฟลเดอร์** (ตอนรันใน terminal) → error หาไฟล์ไม่เจอ
- **วางโฟลเดอร์ซ้อนสองชั้น** เช่น `test_dataset\test_dataset\ts_img_001.jpg` → สคริปต์ไม่เข้าโฟลเดอร์ย่อย จะขึ้น `no images found in test_dataset` ถ้าเปิด `test_dataset` แล้วเห็นโฟลเดอร์ย่อยแทนไฟล์ `.jpg` ให้ดึงไฟล์ขึ้นมาก่อน
- ต่างจากตอนฝึก: ตอนฝึกรู้เฉลยจาก **ชื่อโฟลเดอร์** (`round2\161\xxx.jpg` = ก) แต่วันแข่งภาพทุกใบอยู่รวมโฟลเดอร์เดียว ชื่อไฟล์ไม่บอกเฉลย

## ตารางแปลง class_id ของเวอร์ชัน "ฝัง": ไฟล์ก่อน ตัวฝังเป็นสำรอง

ตอนรัน สคริปต์พิมพ์บอกเสมอว่าใช้ตารางจากไหน (ดูบรรทัด `class_id table:`):

| ข้อความที่ขึ้น | หมายถึง | ต้องทำ |
|---|---|---|
| `CSV file (identical to the built-in copy)` | ใช้ไฟล์ CSV และตรงกับตัวฝัง | ปกติ ไม่ต้องทำอะไร |
| `CSV file …; NOTE it differs from the built-in copy in N folder(s)` | ใช้ไฟล์ CSV (ที่ถูกแก้/เป็นของใหม่) และต่างจากตัวฝัง | ตรวจว่าตั้งใจให้ต่างจริง (เช่นอาจารย์ส่งตารางใหม่มา) |
| `BUILT-IN (embedded in this script)` + `WARNING … not found` / `has N classes` | ไม่มีไฟล์ CSV หรือไฟล์เสีย จึงใช้ตัวฝังแทน | ถ้ามีตารางใหม่จากอาจารย์ ให้ก๊อปไฟล์ CSV มาวางข้างสคริปต์ แล้วรันใหม่ |

ถ้าอาจารย์ส่งตารางใหม่ ก๊อปทับ `Project_1-data_dict.csv` ได้เลย ไม่ต้องแก้โค้ด (ไฟล์มาก่อนตัวฝังเสมอ) เวอร์ชัน "ไม่ฝัง" ก็ใช้ไฟล์ใหม่เช่นกัน
